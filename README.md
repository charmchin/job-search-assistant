# 求职助手

一个面向求职全过程的 macOS 本地 Web 应用。它把招聘链接整理成“是否值得投入、下一步做什么、最晚何时完成”，并管理截止时间、材料缺口、招聘节点和复盘。

## 日常使用

首次安装要求 macOS 13+、Node.js 22.13+（含 npm），并需要联网下载依赖。项目应放在长期保留的位置，应用入口仍依赖源文件夹；详细安装与迁移说明见[使用手册](docs/USER_GUIDE.md)。

1. 首次双击 `install.command`，安装“求职助手.app”和登录启动服务。
2. 今后从 Spotlight、`~/Applications` 或 Dock 打开“求职助手”，无需打开终端。
3. 点击“收集岗位”，粘贴招聘链接；遇到登录或未适配的动态页面时，按界面指引粘贴招聘正文。
4. 核对草稿，填写匹配度、兴趣度、投入决定和明确的下一步，再保存到机会库。

下一步会同步为可完成的真实任务，也可以从已有任务中指定；完成/跳过后首页与卡片同步更新。材料库支持编辑、替换文件引用和删除，机会详情支持新增、编辑、移除材料要求。替换文件/版本后须重新核对就绪；删除引用不会删除本机文件。

任务名称、时间和预计耗时可在机会详情直接编辑。新版表单只保存实际修改的字段；另一窗口改动相关字段时保留输入并提示核对，不静默覆盖。材料就绪核对关联版本，过期的删除确认会被拒绝；升级后请刷新旧页面启用这些保护。

招聘阶段变更会保留独立历史，回退不会抹掉已发生的经历。“节点与记录”可补录遗漏或作废误录；“复盘”按有效历史去重统计，不把面试自动当作参加过笔试。结束原因区分未通过与主动放弃，默认统计保留失败、排除主动放弃。旧库仅保留明确的当前阶段，未知前史和时间不自动补造。

关闭浏览器窗口不会停止后台服务，因此截止提醒仍能工作。需要完全停止时双击 `stop.command`；再次打开“求职助手.app”会自动恢复服务。

`start.command` 保留为免安装启动和故障恢复入口。首次运行会安装缺失依赖、迁移数据库并构建；`.app` 和脚本都会检查内容版本，未变化则复用，代码更新则安全停止旧服务并更新。明确重启当前版本可运行 `./start.command --restart`。端口冲突和启动失败有中文提示，图形入口可直接查看日志。

如需移除应用入口和登录启动项，双击 `uninstall.command`。卸载不会删除数据库和项目源文件。

## 本地数据与 AI

- SQLite 数据库、运行日志与进程信息位于 `~/Library/Application Support/ZhaopinAssistant/`。
- 材料库只保存本机文件路径，不复制或上传文件。
- AI 为可选功能；未配置时使用规则提取，完整手动流程仍可用。
- 粘贴正文可使用离线规则整理；读取招聘链接需要联网。启用 AI 时，正文会发送给配置的接口服务商，费用取决于服务商，不自动上传材料库文件。
- AI 密钥写入 macOS 钥匙串，界面和数据库都不保存明文密钥。
- “设置”页面可导出完整 JSON 备份、机会 CSV，或恢复 JSON 备份。
- 启动器与应用共用同一套 SQL 迁移；结构与成功记录一起提交，重复启动不重跑已完成转换。迁移文件被改动、结构不兼容或版本过旧时会明确拒绝启动，请保留数据和备份，不要删库。

## 开发与验证

开发启动请使用[开发手册第 3 节](docs/DEVELOPER_GUIDE.md#3-本地开发)的独立数据目录和端口示例。不要直接运行未指定数据目录的 `npm run dev` 或 `npm run db:migrate`，这会使用当前用户的正式数据库。

依赖已安装后，以下验证命令自带测试隔离，不需要启动开发服务：

```bash
npm test
npm run test:isolation
npm run test:deps
npm run test:e2e
npm run lint
```

单元测试自动使用独立临时库；端到端测试在临时项目副本中构建、使用独立端口运行，可保持正式服务开启，不修改你的求职数据。详细环境要求及报告位置见开发手册第 11 节。生产 `npm run build` 则必须先停止共享该项目的服务。
